# Creditfy — «Умный кредитный кабинет предпринимателя» (хакатон Альфа-Банк)

Язык общения с владельцем: русский. Он просит делать быстро и без лишних вопросов.
Прежде чем что-то менять, прочитай `docs/PLAN.md` (утверждённый план) и `docs/tz-extract.txt` (текст ТЗ).

## Стек
- backend: FastAPI + SQLAlchemy (SQLite, для облака Postgres), скоринг, конвейер, офферы, ИИ-заглушка. Тесты: `backend/tests`.
- frontend: React 19 + TS + Vite, HashRouter, TanStack Query. `VITE_API_MODE=mock` (по умолчанию) — движок в `src/mock` повторяет бэкенд; live — прокси `/api`.
- стили: один `src/styles.css`, шрифты Montserrat (заголовки) и Manrope (текст). Бренд: красный #EF3124, тёмно-синий #0B1F35, фон #F4F4F6.

## Жёсткие ограничения из ТЗ
- Только синтетические данные; реестры/БКИ — моки. Никаких платных API и закрытых систем в проверяемой версии.
- LLM только с открытыми весами; проверяемая версия обязана работать **без** модели (правила и банк вопросов).
- Основной сценарий целиком внутри продукта (без почты/SMS/звонков), интерфейс только веб.
- Нужны: Docker (запуск одной командой), README, THIRD_PARTY_NOTICES, OpenAPI, схема архитектуры, диаграмма состояний заявки, модель данных, тестовые сценарии, GitHub с историей коммитов.
- Скоринг ≠ решение; ИИ кредитных решений не принимает.
