# ИИ: заглушка сейчас, DeepSeek потом

ТЗ: ИИ приветствуется, но не обязателен; только модели с открытыми весами; никаких платных API. Поэтому:

* **Сейчас** — `StubProvider` (`backend/app/ai/stub.py`): ключевые слова и шаблоны. В интерфейсе всё, что он выдаёт, помечено «ИИ · заглушка», чтобы шаблон не выдавался за вывод модели.
* **Промежуток под DeepSeek** — `backend/app/ai/deepseek.py` (класс `DeepSeekProvider`, методы пока не реализованы). При `LLM_PROVIDER=deepseek` приложение пишет предупреждение и остаётся на заглушке.
* **Запуск модели позже** — локально через Ollama или vLLM (OpenAI-совместимый `/v1/chat/completions`), `LLM_BASE_URL`, `LLM_MODEL`. Платный DeepSeek API использовать нельзя.

## Где ИИ даёт ценность (4 точки подключения, интерфейс `LLMProvider`)
| Метод | Где в продукте | Вход | Выход | Сейчас |
|---|---|---|---|---|
| `recommend_products` | клиент, шаг 1 | описание задачи, сумма | ранжированные продукты с причиной | ключевые слова |
| `summarize_for_underwriter` | карточка заявки в банке | факты заявки, реестры, скоринг | сводка 3–5 предложений | шаблон |
| `explain_status_for_client` | карточка заявки | статус, причины решения | понятное объяснение и следующий шаг | текст статуса |
| `extract_document` | загрузка документа | файл | поля по схеме (выручка, период, ИНН) | `not_available` |

## Правила при подключении
1. Решение по кредиту ИИ **не принимает**: оно остаётся за правилами, скорингом и человеком.
2. В модель уходят только обезличенные признаки (без ИНН, ФИО, телефонов).
3. Ответ валидируется Pydantic-схемой; ошибка или таймаут (20 с) → откат на `StubProvider`.
4. Сводка не должна выдумывать факты: промпт получает только поля из БД, ответ сверяется с ними.
5. Извлечённые из документа значения показываются сотруднику как «предложено моделью» и сверяются с заявленными; расхождение >35% — флаг, как в скоринге.

## Пример промпта для сводки (черновик)
```
Ты помощник кредитного специалиста. Используй только факты ниже, ничего не добавляй.
Факты (JSON): {application, registry, score_factors, flags}
Напиши 3–5 предложений: кто клиент, что просит, что снижает оценку, что проверить. Без рекомендации «одобрить/отказать».
```
