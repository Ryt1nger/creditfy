# Автоматизация без генеративной модели

В сдаваемом MVP разбор потребности, вопросы, подбор продуктов, сводки и статусы используют правила и шаблоны. PDF/XLSX/CSV читают парсеры. Скоринг и кредитное решение детерминированы; генеративная модель не участвует.

`GET /api/ai/status` сохраняет адрес для совместимости и возвращает `mode=rules`, `generative_model_active=false`, список функций без названий моделей. `LLM_ENABLED=0` установлен в Docker и Render-конфигурации; Ollama не входит в стек.

Экспериментальный адаптер `backend/app/ai/llm.py` сохранён с контрактными тестами. Он выключен по умолчанию, не имеет предустановленной модели и не нужен для проверки проекта. Его включение не входит в релизный сценарий. Продуктовые тексты не обещают нейросеть.

В браузерном mock-режиме финансовые значения подставляются из синтетических профилей. Это автономный режим для знакомства с интерфейсом; реальные парсеры проверяются на backend.
