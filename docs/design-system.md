# Дизайн-система (стиль Альфа-Банка)

Принцип: крупные скруглённые карточки на светло-сером фоне, красный как единственный главный акцент, графитовый для текста, крупные жирные заголовки,
плоские «пилюли»-статусы, лайм/фиолет/синий как вторичные акценты (по палитре материалов кейса). Логотип и фирменный шрифт банка не используются: название набрано обычным начертанием.

| Токен | Значение | Применение |
|---|---|---|
| `--red` | `#EF3124` | главные кнопки, активный этап, акценты |
| `--ink` | `#0B1F35` | текст, тёмные карточки, активная навигация |
| `--bg` / карточка | `#F2F3F5` / `#FFFFFF` | фон / поверхности |
| `--lime` | `#ABF000` | «нужно ваше действие», аватары клиентов |
| `--purple` | `#9B3CFF` | сотрудники банка, ИИ-заглушка |
| `--blue` | `#1F5BFF` | процесс идёт |
| `--green` | `#0BA35B` | успех, выдан |
| Радиусы | 24 / 16 / 12 | карточка / кнопка / поле |
| Шрифт | Inter Variable (OFL) | замена фирменному шрифту; 800 для заголовков, −0,035em |

Правила UX: статус всегда говорит человеческим языком и «что дальше»; единственное главное действие на экране — красная кнопка; ошибки объясняют, как исправить;
процесс показан одним степпером из 5 шагов и у клиента, и у банка; все ИИ-элементы помечены; на каждом экране плашка «Демо-прототип».
Состояния: загрузка (скелетоны), пусто, ошибка с повтором, оффлайн-сообщение, адаптивность от 390 px, видимый фокус, `prefers-reduced-motion`.
