# Creditfy — кредитный кабинет предпринимателя

Работающий учебный веб-прототип для хакатона «Альфа-Будущее»: потребность бизнеса → подбор продукта → заявка → документы → проверки → скоринг → автоматическое или ручное решение → подтверждение условий → выдача и график.

Все клиентские данные синтетические. ЕГРЮЛ/ЕГРИП, БКИ и ФНС воспроизведены локально; подписание и выдача не выполняют реальных операций. Продукт не является сервисом Альфа-Банка. Витрина содержит публичные минимальные условия по исследованию на 26.10.2026 со ссылками на банк: до 30 млн ₽ без залога и до 150 млн ₽ с залогом. Расчёт решений — отдельная учебная политика Creditfy, не оферта банка. Генеративная модель в сдаваемом MVP не используется.

## Запуск для проверки

Нужны Docker и Docker Compose. Из корня репозитория:

```bash
docker compose up --build --wait
```

Открыть **http://localhost:8080/#/login**. Кнопка **«Продолжить с готовым кабинетом»** открывает подготовленный кабинет предпринимателя. Сервер выдаёт обычный JWT; банковские права эта кнопка не предоставляет.

API: `http://localhost:8080/api/health`. Swagger внутри сети контейнеров: `http://backend:8000/docs`; снаружи использовать сохранённую спецификацию `docs/openapi.json` или локальный запуск API ниже. Остановка: `docker compose down`. База и загруженные документы сохраняются в именованных томах; **не добавляйте `-v`, если данные нужны**. На другом порту: `WEB_PORT=8088 docker compose up --build --wait`.

### 1. Автоматическое решение и выдача

1. Открыть готовый кабинет → описать: «Нужно 1,5 млн на закупку товара к сезону, на 2 года».
2. В квизе выбрать ООО, возраст 1–3 года → показать подбор → оборотный кредит.
3. Подтвердить сумму и срок → ИНН `7804123453`, заявитель, телефон и роль представителя.
4. «Приложить пример документов»: загружаются настоящие синтетические PDF/XLSX. Проверить числа и источники.
5. При желании «Сохранить и выйти», перезагрузить страницу и продолжить с сохранённого шага.
6. Отправить → получить предложение → принять → подтвердить ознакомление → завершить выдачу. Полный график доступен в карточке.

### 2. Расхождение и ручной разбор

Повторить с ИНН `500123456750`: выручка и оборот расходятся, отправка блокируется до исправления или подтверждения. После отправки заявка переходит специалисту. Войти под `risk@demo.ru`, открыть заявку, запросить пояснение. Клиент отвечает в своей карточке; заявка возвращается специалисту. Подготовить встречное предложение и проверить его у клиента. Оператор `operator@demo.ru` не может принимать кредитное решение.

### 3. Отказ и встречное предложение

ИНН `7722123452` — стоп-фактор кредитной истории; `7705123452` — ликвидация; `7815123455` — молодой бизнес. Готовая заявка Марии показывает поиск доступного срока/суммы вместо немедленного отказа.

## Архитектура и документация

- `frontend/`: React/TypeScript/Vite, HashRouter, TanStack Query; live API либо автономный браузерный режим.
- `backend/`: FastAPI/SQLAlchemy, JWT, обработка PDF/XLSX/CSV, правила подбора, scorecard и кредитный конвейер.
- `docker-compose.yml`: PostgreSQL 16, Python API, nginx с веб-приложением; постоянные тома БД и документов.
- `docs/architecture.md`, `docs/state-diagram.md`, `docs/data-model.md`: схема, состояния и модель данных.
- `docs/openapi.json`, `docs/api/creditfy.postman_collection.json`: спецификация и коллекция запросов.
- `docs/test-scenarios.md`, `docs/research.md`, `THIRD_PARTY_NOTICES.md`: проверка, исследование и сторонние компоненты.

Скоринг (`scorecard-v1`) оценивает факторы риска; решение отдельно учитывает стоп-факторы, лимиты, класс риска и DSCR ≥ 1,25. При нехватке свободного потока сначала увеличивается срок, затем уменьшается сумма. Веса экспертные, не обучены и не откалиброваны на банковских данных. Модель не принимает кредитных решений.

## Конфигурация и сохранность аккаунтов

Пример — `.env.example`. Для production: случайный `JWT_SECRET` не короче 32 символов, `APP_ENV=production`, конкретные `CORS_ORIGINS`, постоянная PostgreSQL. При слабом секрете production не запускается. В MVP API работает **одним worker**: это условие восстановления фонового конвейера, а не распределённая очередь задач.

`POST /api/auth/demo` включён только при `DEMO_ACCESS_ENABLED=1` и `SEED_DEMO=1`, принимает пустой объект и выбирает фиксированный синтетический клиентский профиль. На обычном production его можно выключить.

**Render:** SQLite внутри бесплатного контейнера теряется при пересоздании сервиса — вместе с зарегистрированными аккаунтами. Для исправления нужен `DATABASE_URL` постоянной PostgreSQL, а не повторная регистрация. `render.yaml` описывает связку сервисов с PostgreSQL; он не меняет существующие сервисы сам. У бесплатной БД есть ограничения срока действия, уточните их в панели провайдера. Загруженные файлы без постоянного диска не переживают пересоздание API; для сдачи надёжный воспроизводимый вариант — Docker с томами. Не отправляйте настоящие финансовые документы.

Существующие адреса: https://creditfy-web.onrender.com и https://creditfy-api.onrender.com. Они могут показывать предыдущую сборку до обновления сервиса.

## Разработка без Docker

API: из `backend/` запустить `uvicorn app.main:app --port 8000`. Данные SQLite сохраняются в `backend/data/`.
Frontend: `cd frontend && VITE_API_MODE=live npm run dev`. Vite проксирует `/api` на `http://localhost:8000`; другой адрес задаётся через `VITE_PROXY_TARGET`.

Автономный режим: `VITE_API_MODE=mock npm run dev`. Он хранит данные только в localStorage этого браузера и сайта, а токен — в sessionStorage. Регистрация в нём не создаёт аккаунт на live-сервере; контексты токенов разделены. Чтение файлов имитируется по синтетическим профилям, парсеры работают на backend.

## Границы MVP

Овердрафт доступен для ознакомления: новый аннуитетный расчёт и оформление отключены, поскольку проценты зависят от фактического использования лимита и дней. Исторические примеры сохранены. OCR сканов, реальная ЭП, денежные переводы, refresh-токены, антивирус и распределённая обработка не реализованы. Публичные условия базовых программ нормализованы из исследования; обычная и скидочная ставки разделены. Полный исследовательский каталог — docs/product-research.json. Кредитные линии, карты, факторинг и гарантии не выдаются за обычный аннуитетный кредит. Исторические заявки используют снимок условий; прежние предложения и кредиты не пересчитываются.
